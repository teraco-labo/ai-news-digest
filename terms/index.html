基礎

AGI
人間ができる知的作業を、分野を問わず一通りこなせるAIのことです。まだ実現しておらず、定義自体も定まっていません。
AIスロップ
AIに作らせただけの、中身が薄い文章やコードのことです。数だけ多くて役に立たないものを指す、やや否定的な言い方です。
CAPTCHA
ウェブサイトで「あなたは人間ですか」を確かめるための仕組みです。ゆがんだ文字を読ませたり、写真の中から信号機を選ばせたりするあれです。
Lean 4
数学の証明をコンピュータに検証させるための言語です。書いた証明に穴があれば機械が指摘してくれます。
LLM
大量の文章を学習して、人間のように読み書きできるAIのことです。ChatGPTやClaudeの「頭脳」にあたる部分がこれです。
MoE
AIの内部を複数の専門家に分け、質問ごとに必要な担当だけを動かす設計です。
recurrent depth
AIが答えを出す前に、頭の中で同じ処理を何度も繰り返して考えを深めるやり方です。言葉を順番に書き出しながら考えるのではなく、表に出ない形で考えます。
Transformer
今のAIブームを支えている、AIの内部構造の設計図です。2017年にGoogleの研究者が発表しました。
エージェントスワーム
たくさんのAIエージェントを同時に動かし、手分けして作業させるやり方です。一体では時間のかかる仕事を並行して進められます。
コンテキストウィンドウ
AIが一度に読み込んで覚えていられる文章の量のことです。「短期記憶の広さ」と考えると分かりやすいです。
ステム分離
混ざって1本になっている曲の音を、歌・ドラム・ベースなどのパートごとに分けることです。分けた後のパートそれぞれを「ステム」と呼びます。
デッドインターネット理論
ネット上の書き込みや画像の多くが、人ではなく機械によって作られたものになっているという見方です。人同士のやり取りが見かけほど残っていない、という主張です。
トークン
AIが文章を扱うときの最小単位です。英語ならおよそ単語1つ、日本語なら1〜2文字が1トークンにあたります。
ナビエ・ストークス方程式
水や空気の流れ方を表す数式です。式はあるのに、解が必ず存在するかどうかが未解決のままです。
パラメータ
AIの中にある調整つまみのようなもので、学習によって値が決まります。数が多いほど複雑なことを覚えられます。
プログラム解析
プログラムを実際に動かす前や動かしながら、その中身の性質を機械的に調べる技術です。どの値がどこまで影響するかを追いかけます。
マルチモーダル
文章だけでなく、画像・音声・動画も一緒に扱えるAIのことです。写真を見せて質問できるのはこの能力によるものです。
ミレニアム懸賞問題
数学の未解決問題のうち、特に重要とされる7つです。1問解くごとに100万ドルの賞金が出ます。
ロボタクシー
運転手が乗っていないタクシーのことです。AIが車を運転して客を目的地まで運びます。
ロボットアーム
人の腕のように動く機械の腕です。工場で物をつかんだり組み立てたりするのに使われます。
ローカルファースト
データをまず自分の端末に置き、外部のサーバーには預けないことを優先する作り方です。
世界モデル
物理法則や物事の因果関係をAIが内部に持つ仕組みのことです。
小規模言語モデル
スマートフォンやパソコン内で動かせるほど小さいAIのことです。大きなモデルの手軽な代替になります。
強化学習
うまくいったら褒める、失敗したら褒めないという繰り返しでAIを上達させるやり方です。ゲームやロボットの動作の学習でよく使われます。
生成AI
文章・画像・音声・動画などを新しく作り出せるAIの総称です。分類や予測をするだけだった従来のAIとの違いがここにあります。
身体性AI
ロボットなど物理的な身体を持ち、実世界で動作するAIのことです。

使い方

AIエージェント
指示を受けて、自分で手順を考えながら複数の作業を実行してくれるAIのことです。「答える」から「やってくれる」への進化です。
Claude Code
Claudeにコードを書かせたり直させたりするための道具です。ファイルの編集から変更の記録まで任せられます。
Codex
OpenAI が提供している、プログラムを書く作業を任せるためのAIです。人が指示を出すと、コードを書いたり直したりします。
Engrim
複数のAIツールに、共通の記憶を持たせるための道具です。毎回同じ説明をし直す手間を減らします。
Google AI Mode
Googleの検索で、リンク一覧の代わりにAIがまとめた答えを返す仕組みです。商品の候補もAIが選んで示します。
Google Pics
Google が出したデザイン制作ツールです。自分で配置するのではなく、作りたいものを言葉で指示すると形になります。
LoRA
AIの一部だけを軽く追加学習させる手法です。少ない計算資源で個性を足せます。
MCP
AIと外部サービスをつなぐための共通の規格です。AI版のUSB端子のようなものだと考えると分かりやすいです。
Microduck
Hugging Face が売り出した399ドルのアヒル型ロボットです。設計が公開されていて、誰でも中身を見られます。
RAG
AIに社内資料や最新情報を検索させてから答えさせる仕組みです。AIが知らないことを補うための定番の方法です。
RLHF
人間の評価を使ってAIの返答を好ましい方向に調整する訓練方法です。
StemDeck
曲をボーカルや楽器ごとのパートに分けてくれる無料のソフトです。インターネットに送らず、自分のパソコンの中だけで処理します。
インシデント対応
サービスが止まったり不具合が出たときに、原因を突き止めて元に戻す作業のことです。夜中でも呼び出されることがある仕事です。
エンベディング
文章の意味を数字の並びに変換したものです。意味が近い文どうしは数字も近くなるため、検索に使えます。
エージェント型コーディング
AIが自分でファイルを読み書きし、テストを実行しながらプログラムを完成させる開発の進め方です。
ツール呼び出し
AIが必要に応じて外部の機能（検索・計算・API）を自分で使うことです。AIエージェントの土台になる仕組みです。
ハルシネーション
AIが事実でないことを、もっともらしい口調で答えてしまう現象です。日本語では「幻覚」と訳されます。
ファインチューニング
既存のAIに追加学習をさせて、特定の用途や文体に合わせて調整することです。
プルリクエスト
作業用に分けて書いたコードを、本体に入れてよいか確認する場のことです。中身を見せ合ってから合流させます。
プロンプト
AIに与える指示や質問の文章のことです。書き方しだいで返ってくる答えの質が大きく変わります。
ベクトルデータベース
エンベディングを保存し、意味の近さで高速に検索できるデータベースです。RAGを支える裏方です。
思考の連鎖
AIに答えを出す前に考える過程を書かせることで、正答率を上げる手法です。
推論
学習済みのAIを実際に動かして答えを出させることです。AIを「使う」場面はすべて推論にあたります。
温度パラメータ
AIの答えのばらつき具合を決める設定です。低いほど堅実、高いほど自由な発想になります。
蒸留
大きくて賢いAIの振る舞いを、小さなAIに教え込んで再現させる技術です。
量子化
AIの内部の数値を粗くして、動作を軽く・省メモリにする技術です。多少の精度と引き換えに実用性を取ります。

ソフトウェアの中身が公開され、誰でも自由に使ったり改良したりできる形態のことです。
ガスタービン
燃料を燃やした勢いで羽根車を回し、電気を作る装置です。設置が比較的早く済み、大きな電力をまかなえます。
ソブリンAI
自分の国の中でAIを動かし、データも国内に置こうという考え方です。他国の会社に頼りきりにならないことが目的です。
データセンター
AIを動かすためのコンピュータを大量に設置した施設です。AI競争は電力と土地の競争でもあります。
ネオクラウド
AI向けの計算機を大量に持ち、時間貸しする新しいタイプの事業者のことです。大手クラウドとは違い、AIの計算に絞ってサービスを提供します。
パッケージレジストリ
ソフト作りに使う部品を、みんなが取り寄せられるようにまとめて置いてある場所です。言語ごとに代表的な置き場があります。
ロボットデータ
ロボットに動き方を覚えさせるために集める、実際の動作の記録です。カメラの映像や、関節をどう動かしたかといった情報が含まれます。
可逆計算
計算のときに捨てている熱を、捨てずに回収して使い直す方式です。消費電力を根本から減らそうという考え方です。
投機的デコーディング
小さくて速いAIに先に答えの続きを予想させ、本命の大きなAIがまとめて答え合わせをするやり方です。待ち時間を短くできます。
推論コスト
AIを動かすたびにかかる費用のことです。AIサービスの採算を左右する最も重要な数字です。
計算資源
AIの学習や実行に使う計算能力の総量のことです。お金・電力・半導体の量とほぼ同じ意味で語られます。

安全性

Apple Reference Image
写真が編集されているかどうかを確かめるためのAppleの仕組みです。AIによる加工も対象です。
ASCIIスマグリング
人間の目には見えない文字を文章に混ぜて、隠した命令を送り込む手口です。画面上は普通の文にしか見えません。
Conti
企業のデータを勝手に暗号化して身代金を要求していた犯罪グループの名前です。今回、その関係者に実刑判決が出ました。
METR
AIの能力やリスクを外部から検証する組織です。企業の言い分をそのまま受け取らず、自分たちで測ります。
アライメント
AIが人間の意図や価値観からずれないようにする研究分野です。日本語では「整合性」と訳されます。
ガードレール
AIが不適切な出力をしないように設ける制限や検査の仕組みです。
サンドボックス
プログラムを外とつながらない閉じた場所で動かす仕組みです。中で何が起きても外側に被害が広がらないようにします。
ジェイルブレイク
AIにかけられた制限を、言葉の工夫ですり抜けさせる行為です。
ディープフェイク
AIで作られた、本物と見分けがつかない偽の映像や音声のことです。
プロンプトインジェクション
AIに読ませる文章の中に不正な指示を混ぜ込み、意図しない動作をさせる攻撃です。
ランサムウェア
パソコンやサーバーの中身を勝手に暗号化して開けなくし、元に戻す代わりにお金を要求する攻撃です。病院や工場が止まる被害も起きています。
レッドチーミング
AIをわざと攻撃して弱点を探す検証作業のことです。公開前の安全確認として行われます。
自己改善AI
AIが自分自身の弱点を見つけて直していく仕組みのことです。人が手を入れなくても性能や安全性が上がっていくことを目指します。
電子透かし
AIが作ったものだと後から判別できるように、生成物に埋め込む見えない印です。

規制

AIと著作権
AIの学習に他人の著作物を使ってよいか、AIの生成物に著作権が生じるかという論点です。
AI安全研究所
AIの危険性を政府として評価するために各国が設けた機関です。
EFF
インターネット上の利用者の権利を守る活動をしている非営利団体です。裁判所や政府に意見を出すこともあります。
EU AI Act
EUが世界に先駆けて作った、AIを包括的に規制する法律です。用途のリスクに応じて義務が変わります。
ペンタゴン（米国防総省）
アメリカの軍事を統括する政府機関です。庁舎が五角形をしていることからこの通称で呼ばれます。
半導体輸出規制
高性能なAI半導体を特定の国へ売ることを制限する政策です。
反トラスト法
競合する会社同士が示し合わせて市場を操作することを禁じる法律です。価格や生産量を談合で決めるのが典型的な違反にあたります。
合成データ
AI自身が作り出した学習用のデータのことです。本物のデータが足りないときに使われます。
学習データ
AIを訓練するために読み込ませる大量のデータのことです。AIの性能と偏りの両方を決める土台です。

評価

Artificial Analysis
いろいろな会社のAIモデルを同じ条件で試して、賢さや速さ、値段を一覧にして公開しているところです。どのモデルを使うか選ぶときの比較表として使われます。
ベンチマーク
AIの性能を共通のテストで測るための指標です。モデル同士の比較に使われます。

ビジネス

Accel
アメリカのベンチャーキャピタル（投資会社）です。創業間もない企業に出資します。
Andreessen Horowitz
アメリカの大手ベンチャーキャピタルです。a16z（エーイチロクゼット）とも呼ばれます。
ARR
月額や年額で継続して支払われるサービスが、1年間で受け取る見込みの売上です。契約が続く前提で計算します。
IPO
企業が株式を証券取引所に上場し、誰でも売買できるようにすることです。新規株式公開ともいいます。
Y Combinator
創業直後の企業を育てるアメリカの支援プログラムです。YCと略されます。
シリーズB
会社が外部の投資家からお金を集める段階のうち、2回目のまとまった調達を指します。製品ができて、これから広げていく時期に行われます。
ステルスモード
新しい会社が、事業の中身を公表せずに開発を進めている状態のことです。準備が整った段階で表に出てきます。
フォワードデプロイドエンジニア
顧客の会社に入り込んで、その場で実装まで手を動かす技術者のことです。売って終わりにしない売り方です。
ベンチャーキャピタル
将来性のある未上場企業に出資して、成長後の株式売却で利益を得る投資会社です。
外部トラスティ
会社の外にいて、経営を監督する立場の人たちです。株主とは別の視点から会社の方針を縛ります。
文芸エージェント
作家に代わって出版社と交渉する代理人です。契約をまとめ、その報酬の一部を受け取ります。
評価額
投資を受ける際に算定される企業の価値のことです。「10億ドルの評価額で調達」のように使われます。
資金調達ラウンド
スタートアップが投資家からお金を集める段階のことです。シード、シリーズA、Bと進みます。

Ars Technica

Newsday

SemiAnalysis

TechCrunch
スタートアップと技術業界を専門に扱うアメリカのニュースメディアです。
The Seattle Times
米国シアトルで発行されている地方紙です。OpenAIとMicrosoftを著作権侵害で訴えました。
Wired

Z-Library
